# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.15] - 2026-05-09

### Changed
- Bumped version to 0.1.15 in plugin header, script enqueues, and block style registration for consistent release tagging

## [0.1.14] - 2026-05-09

### Fixed
- Fixed border styling issues in card view

## [0.1.13] - 2026-05-09

### Changed
- Adjusted mobile card div structure and styling

## [0.1.12] - 2026-05-09

### Removed
- Removed borders from card view for a cleaner look

## [0.1.11] - 2026-05-09

### Changed
- Updated card layout so label and value are stacked vertically

## [0.1.10] - 2026-05-09

### Fixed
- Fixed label duplication and visibility issues in card view

## [0.1.9] - 2026-05-09

### Fixed
- Fixed header handling in card view when using table headers

## [0.1.8] - 2026-05-09

### Changed
- Improved horizontal scroll behavior using a combination of JavaScript and CSS
- Added dynamic `min-width` handling for better content fitting

## [0.1.7] - 2026-05-09

### Changed
- Further refinements to horizontal scroll behavior

## [0.1.6] - 2026-05-09

### Fixed
- Removed `white-space: nowrap` from table cells in horizontal scroll mode to prevent content overflow

## [0.1.5] - 2026-05-09

### Added
- Initial implementation of responsive modes (Horizontal Scroll and Cards)
- Basic sidebar controls in the Table block
- Conditional asset loading
- Foundation for card view and scroll view
